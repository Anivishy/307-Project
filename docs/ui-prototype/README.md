# RecipeCollab Figma mockups

These SVG frames were generated from `307 Kickoff Presentation.pdf`.

Last updated: May 1, 2026

## Files

- `recipe-collab-all-frames.svg` - one large board with every screen.
- `00-app-flow.svg` - sitemap / page-flow overview.
- `01-landing.svg` - landing page with Get Started and Sign In.
- `02-login.svg` - login screen with validation/success feedback.
- `03-dashboard.svg` - post-login dashboard.
- `04-profile-ingredients.svg` - profile and ingredient manager.
- `05-groups.svg` - groups list.
- `06-group-detail-recipe-generator.svg` - group detail with recipe generator.
- `07-ingredient-approvals.svg` - approval page/state for ingredient requests.

## Figma import

Open Figma, then drag any SVG file onto the canvas. For the fastest start, drag in `recipe-collab-all-frames.svg`; if you want cleaner per-page layers, import the individual SVG files.

The screens are designed as 1440 x 1024 desktop web-app frames because the kickoff deck describes a custom web app.
